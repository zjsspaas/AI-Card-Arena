# Agent 对话使用指南

## 快速开始

### 1. 启动服务

```bash
go run main.go
```

服务将在 `http://localhost:8080` 启动。

### 2. 与 Agent 对话

#### 方法一：使用 curl 命令

##### 与 Chat Agent 对话

**基本对话（使用默认会话）：**
```bash
curl -X POST http://localhost:8080/api/v1/agents/chat/process \
  -H "Content-Type: application/json" \
  -d '{"message": "你好"}'
```

**使用自定义会话 ID（推荐，可以保存对话历史）：**
```bash
curl -X POST http://localhost:8080/api/v1/agents/chat/process \
  -H "Content-Type: application/json" \
  -d '{
    "message": "你好",
    "params": {
      "session_id": "my_session_001"
    }
  }'
```

**继续对话（使用相同的 session_id）：**
```bash
curl -X POST http://localhost:8080/api/v1/agents/chat/process \
  -H "Content-Type: application/json" \
  -d '{
    "message": "你叫什么名字？",
    "params": {
      "session_id": "my_session_001"
    }
  }'
```

##### 与 DeepSeek Agent 对话

**基本对话：**
```bash
curl -X POST http://localhost:8080/api/v1/agents/deepseek/process \
  -H "Content-Type: application/json" \
  -d '{"message": "你好"}'
```

**流式响应对话（推荐，可获得实时反馈）：**
```bash
curl -X POST "http://localhost:8080/api/v1/agents/deepseek/process?stream=true" \
  -H "Content-Type: application/json" \
  -d '{"message": "请解释一下人工智能的概念"}'
```

#### 使用 Python 与 DeepSeek Agent 对话
```python
import requests

# 标准响应模式
url = "http://localhost:8080/api/v1/agents/deepseek/process"
payload = {
    "message": "请解释Go语言的优势"
}

response = requests.post(url, json=payload)
result = response.json()
print(result['data']['result'])

# 流式响应模式
import requests

url = "http://localhost:8080/api/v1/agents/deepseek/process?stream=true"
payload = {
    "message": "请写一段Python代码实现快速排序算法"
}

response = requests.post(url, json=payload, stream=True)

if response.status_code == 200:
    for chunk in response.iter_content(chunk_size=8192):
        if chunk:
            print(chunk.decode('utf-8'), end='')
else:
    print(f"请求失败: {response.status_code}")
```

#### 方法三：使用 JavaScript/Node.js

#### 使用 JavaScript 与 Chat Agent 对话

```javascript
const axios = require('axios');

async function chat(message, sessionId = 'default') {
  const response = await axios.post(
    'http://localhost:8080/api/v1/agents/chat/process',
    {
      message: message,
      params: {
        session_id: sessionId
      }
    }
  );
  
  return response.data.data.result;
}

// 使用示例
(async () => {
  const sessionId = 'js_user_001';
  console.log(await chat('你好', sessionId));
  console.log(await chat('你叫什么名字？', sessionId));
})();
```

#### 使用 JavaScript 与 DeepSeek Agent 对话

```javascript
const axios = require('axios');

// 标准响应模式
async function deepseekChat(message) {
  const response = await axios.post(
    'http://localhost:8080/api/v1/agents/deepseek/process',
    {
      message: message
    }
  );
  
  return response.data.data.result;
}

// 流式响应模式
const https = require('https');
const querystring = require('querystring');

async function deepseekStreamChat(message) {
  return new Promise((resolve, reject) => {
    const data = querystring.stringify({ message: message });
    
    const options = {
      hostname: 'localhost',
      port: 8080,
      path: '/api/v1/agents/deepseek/process?stream=true',
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Content-Length': Buffer.byteLength(JSON.stringify({ message: message }))
      }
    };
    
    const req = https.request(options, (res) => {
      res.setEncoding('utf8');
      
      res.on('data', (chunk) => {
        process.stdout.write(chunk); // 实时输出流式内容
      });
      
      res.on('end', () => {
        resolve();
      });
    });
    
    req.on('error', (e) => {
      reject(e);
    });
    
    req.write(JSON.stringify({ message: message }));
    req.end();
  });
}

// 使用示例
(async () => {
  console.log("=== 标准响应模式 ===");
  const standardResult = await deepseekChat('请解释Go语言的优势');
  console.log(standardResult);
  
  console.log("\n=== 流式响应模式 ===");
  await deepseekStreamChat('请详细介绍JavaScript的异步编程');
})();
```

## 对话功能说明

### 会话管理

- **session_id**: 用于区分不同的对话会话
  - 如果不提供 `session_id`，将使用默认会话 "default"
  - 相同的 `session_id` 会共享对话历史
  - 不同的 `session_id` 拥有独立的对话历史

### 对话历史

每次对话的响应中会包含完整的对话历史：

```json
{
  "success": true,
  "data": {
    "result": "Agent 的回复",
    "status": "success",
    "data": {
      "session_id": "user123",
      "history": [
        {
          "role": "user",
          "content": "你好"
        },
        {
          "role": "assistant",
          "content": "你好！我是 Chat Agent..."
        }
      ]
    }
  }
}
```

## 接入真实的 AI 模型

### DeepSeek Agent

本项目已内置 DeepSeek Agent，它已接入 DeepSeek 的真实 AI 模型。你可以直接使用，无需额外配置。

**主要特性：**
- 支持标准 HTTP 响应和流式响应两种模式
- 自动处理对话历史
- 支持中文和英文等多种语言

**使用方法：**
```bash
# 标准响应模式
curl -X POST http://localhost:8080/api/v1/agents/deepseek/process \
  -H "Content-Type: application/json" \
  -d '{"message": "你的任务是什么？"}'

## 常见问题

**Q: 如何开始新的对话？**
A: 使用一个新的 `session_id` 即可开始新的对话。

**Q: 对话历史会保存多久？**
A: 对话历史保存在内存中，服务重启后会丢失。如果需要持久化，可以修改代码将历史保存到数据库。

**Q: 可以同时进行多个对话吗？**
A: 可以，使用不同的 `session_id` 即可。

**Q: 如何查看对话历史？**
A: 每次对话的响应中都包含完整的对话历史，查看 `data.data.history` 字段即可。

**Q: DeepSeek Agent 支持流式响应吗？**
A: 支持，在请求 URL 中添加 `?stream=true` 参数即可使用流式响应模式，这会提供更流畅的对话体验。

**Q: 如果端口 8080 被占用怎么办？**
A: 可以使用环境变量指定其他端口，例如：
```bash
# 在 Windows PowerShell 中
$env:PORT='8888'; go run main.go

# 在 Linux/Mac 终端中
export PORT=8888 && go run main.go
```
