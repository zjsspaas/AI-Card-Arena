# Agent 对话使用指南

## 快速开始

### 1. 启动服务

```bash
go run main.go
```

服务将在 `http://localhost:8080` 启动。

### 2. 与 Agent 对话

#### 方法一：使用 curl 命令

**基本对话（使用默认会话）：**
```bash
curl -X POST http://localhost:8080/api/v1/agents/chat/process \
  -H "Content-Type: application/json" \
  -d '{"message": "你好"}'
```

**使用自定义会话 ID（推荐，可以保存对话历史）：**
```bash
curl -X POST http://localhost:8080/api/v1/agents/chat/process \
  -H "Content-Type: application/json" \
  -d '{
    "message": "你好",
    "params": {
      "session_id": "my_session_001"
    }
  }'
```

**继续对话（使用相同的 session_id）：**
```bash
curl -X POST http://localhost:8080/api/v1/agents/chat/process \
  -H "Content-Type: application/json" \
  -d '{
    "message": "你叫什么名字？",
    "params": {
      "session_id": "my_session_001"
    }
  }'
```

#### 方法二：使用 Python 脚本

运行示例脚本：
```bash
cd examples
python3 chat_example.py
```

或者自己编写 Python 代码：
```python
import requests

url = "http://localhost:8080/api/v1/agents/chat/process"
payload = {
    "message": "你好",
    "params": {
        "session_id": "user123"
    }
}

response = requests.post(url, json=payload)
result = response.json()
print(result['data']['result'])
```

#### 方法三：使用 JavaScript/Node.js

```javascript
const axios = require('axios');

async function chat(message, sessionId = 'default') {
  const response = await axios.post(
    'http://localhost:8080/api/v1/agents/chat/process',
    {
      message: message,
      params: {
        session_id: sessionId
      }
    }
  );
  
  return response.data.data.result;
}

// 使用示例
(async () => {
  const sessionId = 'js_user_001';
  console.log(await chat('你好', sessionId));
  console.log(await chat('你叫什么名字？', sessionId));
})();
```

## 对话功能说明

### 会话管理

- **session_id**: 用于区分不同的对话会话
  - 如果不提供 `session_id`，将使用默认会话 "default"
  - 相同的 `session_id` 会共享对话历史
  - 不同的 `session_id` 拥有独立的对话历史

### 对话历史

每次对话的响应中会包含完整的对话历史：

```json
{
  "success": true,
  "data": {
    "result": "Agent 的回复",
    "status": "success",
    "data": {
      "session_id": "user123",
      "history": [
        {
          "role": "user",
          "content": "你好"
        },
        {
          "role": "assistant",
          "content": "你好！我是 Chat Agent..."
        }
      ]
    }
  }
}
```

```bash

```

## 常见问题

**Q: 如何开始新的对话？**
A: 使用一个新的 `session_id` 即可开始新的对话。

**Q: 对话历史会保存多久？**
A: 对话历史保存在内存中，服务重启后会丢失。如果需要持久化，可以修改代码将历史保存到数据库。

**Q: 可以同时进行多个对话吗？**
A: 可以，使用不同的 `session_id` 即可。

**Q: 如何查看对话历史？**
A: 每次对话的响应中都包含完整的对话历史，查看 `data.data.history` 字段即可。
